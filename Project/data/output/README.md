# Generated output data

All files in this directory are generated by `python scripts/generate_all.py`.

- `constants_summary.csv`: physical constants and derived lunar quantities.
- `ideal_orbit_family.csv`: dense ideal horizontal surface-orbit family versus `u=v/v_c`.
- `ideal_reference_cases.csv`: reference values quoted in the paper.
- `speed_energy_comparison.csv`: MLB benchmark, circular, and escape speed/energy comparison.
- `angle_sensitivity.csv`: exact and asymptotic early-impact shortfall.
- `finite_height_tolerance.csv`: maximum safe flight-path angle versus launch height.
- `monte_carlo_launches.csv`: reproducible 100,000-sample launch ensemble (`seed=1600`).
- `monte_carlo_summary.csv`: ensemble settings and survival fraction.
- `rotation_miss_by_latitude.csv`: one-orbit rotation displacement for selected orbit families.
- `rotation_resonances.csv`: ideal one-lunar-rotation resonance family.
- `near_circular_resonances.csv`: the twelve highest-order resonances.
- `rotation_summary.csv`: key rotation scales.
- `perturbation_case_definition.csv`: complete initial definition of the M0--M4 test case.
- `perturbation_model_comparison.csv`: one-reference-period model comparison.
- `acceleration_scale_comparison.csv`: central, degree-2, Earth-tide, and Sun-tide magnitudes.
- `terrain_envelope_requirements.csv`: mean-sphere and conservative global-envelope launch requirements.
- `numerical_convergence.csv`: central-orbit step/tolerance verification.
- `validation_report.txt`: analytic/numerical consistency tests.
- `ldem4_status.txt`: explains how to enable optional LOLA calculations.

Optional, created only after downloading LDEM4:

- `ldem4_computed_statistics.csv`
- `ldem4_groundtrack_clearance.csv`
