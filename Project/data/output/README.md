# Derived output data

Every file in this directory is generated by a versioned script. Raw NASA
products belong in `data/external/`, not here.

## Analytic and low-order results

- `ideal_*`, `angle_sensitivity.csv`, `finite_height_tolerance.csv`, and
  `monte_carlo_summary.csv` support the ideal-model analysis.
- `rotation_*` and `near_circular_resonances.csv` support rotation and
  resonance analysis.
- `perturbation_*` and `acceleration_scale_comparison.csv` support the
  transparent degree-2 and fixed third-body hierarchy.
- `terrain_envelope_requirements.csv` uses the scanned LDEM64 maximum as a
  conservative global elevation envelope.

## High-fidelity results

- `gravity_degree_convergence.csv` and `gravity_model_selection.csv` document
  the GRGM1200B truncation study.
- `high_fidelity_case_*` contains the degree-600 nominal return, direct Newton
  correction history, trajectory, and local sensitivities.
- `high_fidelity_integrator_crosscheck.csv` and
  `high_fidelity_gravity_order_crosscheck.csv` separate integration
  differences from observed truncation-model discrepancies.
- `high_fidelity_corridor_profile.csv` and `ldem64_global_heatmap_*` support
  the LDEM64 visualizations.
- `near_surface_*` contains the bounded terrain and release-height studies.

## Solver and web validation

- `general_degree600/` is a retained general-solver example, not a temporary
  smoke-test directory.
- `web_gravity_atlas_validation.json`, `web_solver_crosscheck.json`, and
  `web_terrain_tile_validation.json` compare browser products with the direct
  Python models.
- `validation_report.txt` records the packaged consistency checks. A skipped
  raw-source check is distinct from a failed derived-result check.

Logs, error streams, Python caches, temporary solver runs, the superseded
LDEM4 products, and the superseded degree-2 targeted-return products are not
versioned.
